# Money Calculator

Three everyday money tools in one page: a profit-margin and markup calculator, a tip and split-bill calculator, and a discount / sale-price calculator.

**Live app:** https://darenazhekbarovaboba-source.github.io/money-calculator/

## What it does

- **Profit & markup** — enter cost and selling price to get profit, margin %, and markup %. Optionally find the price you need for a target margin or markup.
- **Tip & split** — add a tip (with 15 / 18 / 20 / 25% shortcuts) and split the bill across any number of people. Optionally round each share up to the next dollar.
- **Discount** — take a percent or a dollar amount off a price and see the sale price, savings, and effective percent off.

Your last inputs are saved only in this browser with `localStorage`. There is no account and no server.

## Run locally

Open `index.html` in a browser, or serve the folder with any static file server.
